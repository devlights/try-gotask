# v3.52.0で `--temp-dir` オプションが追加

[v3.52.0](https://taskfile.dev/docs/changelog#v3-52-0-2026-07-02) にて、`--temp-dir`オプションが追加されました。

その名前の通り、[task](https://taskfile.dev/)が一時ディレクトリとして使用する場所を指定するものです。

元々存在していた [TASK_TEMP_DIR環境変数](https://taskfile.dev/docs/guide#by-fingerprinting-locally-generated-files-and-their-sources) と同様の動きとなります。
